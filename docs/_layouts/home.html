About the Project

TDisplayS3 Adventure is a modular mini-game engine for the LilyGo T-Display-S3 (ESP32-S3, 320x170 ST7789 display, 2 buttons: A=BOOT=GPIO0, B=GPIO14, both active LOW). Games know neither GPIOs nor display drivers - only the interfaces in src/core/. Additional boards can be added via a single file in src/boards/ and an entry in platformio.ini.

Stack: PlatformIO + Arduino + TFT_eSPI 2.5.43 (pinned). All games render into a PSRAM framebuffer (TFT_eSprite) and push once per frame - flicker-free at ~60 FPS. The engine runs a launcher menu; every game is controlled entirely with the board's two buttons.

Hardware: 16 MB flash (3 MB app + ~13 MB FATFS), 8 MB octal PSRAM (qio_opi), USB CDC on boot. Build & flash: 

pio run -t upload      # build and flash
pio device monitor     # serial monitor (115200 baud)
